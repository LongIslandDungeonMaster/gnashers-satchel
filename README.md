# Gnasher's Satchel

A player's character sheet for D&D that runs from one file. Download it, open it on your phone or laptop, and it works with the wifi off. No account, no install, no subscription, and nothing you type leaves your device.

**Download:** the latest build is on the [Releases](https://github.com/LongIslandDungeonMaster/gnashers-satchel/releases) page as `gnashers-satchel.html`. It is the same file offered at [longislanddungeonmaster.com/satchel](https://longislanddungeonmaster.com/satchel) and on [itch.io](https://longislanddungeonmaster.itch.io/gnashers-satchel).

## What it does

- A full 5e character sheet with the free SRD 5.2.1 rules inside: classes, spells, items and conditions, nothing to look up elsewhere.
- Every roll is one tap, and every roll card offers the same roll again at advantage or disadvantage.
- A spellbook, an inventory and the party's shared loot and coin.
- Pair with the Dungeon Master's [Gnasher's Grimoire](https://github.com/LongIslandDungeonMaster/gnashers-grimoire) by typing a code, and the battle map, initiative, handouts, whispers, recaps and the campaign map land on your screen as the DM reveals them.
- Runs unpaired too: it is a sheet first, a table second.

## How to run it

1. Download `gnashers-satchel.html`.
2. Open it in a current browser on a phone, tablet or computer.
3. That is all. Keep the file anywhere and your characters stay in the browser's storage on that device.

## What it is not

It is not a virtual tabletop for remote play and it has no server. The pairing talks to the DM's screen at the same table.
